# 🚀 AutoFollow X — Premium Edition

## 📦 Что это?
Мощный инструмент для автоматизации работы с Twitter/X с современным GUI и управлением через Telegram.

---

## ⚠️ ВАЖНО - Перед первым запуском!

### Требуется установить браузеры Playwright:

**Вариант 1 - Автоматический:**
При первом запуске приложение само попытается установить браузеры.

**Вариант 2 - Вручную:**
```bash
python -m playwright install chromium
```

**Вариант 3 - Через скрипт:**
Запустите файл `install-browsers-and-build.bat`

## 🚀 Быстрый старт

### 1️⃣ Первый запуск
```
Дважды кликните на AutoFollow-X.exe
```

При первом запуске:
- Приложение автоматически проверит наличие браузеров
- Если браузеров нет - попытается их установить
- Это может занять 2-5 минут в зависимости от интернета

### 2️⃣ Проверка прокси (опционально)
- Нажмите **"✅ Проверить прокси"**
- Введите прокси в формате: `http://user:pass@ip:port`

### 3️⃣ Проверка cookies (для авторизации)
- Нажмите **"🍪 Проверить cookies"**
- Выберите файл с cookies в формате JSON

### 4️⃣ Загрузка списка профилей
- Нажмите **"📂 Выбрать файл"**
- Выберите `.txt` файл со строками в формате: `имя ссылка`

### 5️⃣ Запуск
- Нажмите **"▶️ Старт"**
- Отслеживайте прогресс в реальном времени!

## 🔧 Устранение проблем

### ❌ "Executable doesn't exist" / "chromium"
**Проблема:** Браузеры Playwright не установлены

**Решение:**
```bash
python -m playwright install chromium
```
Или запустите `install-browsers-and-build.bat`

### ❌ "ERR_PROXY_CONNECTION_FAILED"
**Проблема:** Прокси не работает или неверный формат

**Решение:**
1. Проверьте прокси через кнопку "✅ Проверить прокси"
2. Убедитесь в формате: `http://user:pass@ip:port`
3. Или оставьте поле пустым для работы без прокси

### ❌ Приложение не запускается
**Решение:**
1. Убедитесь что все файлы в одной папке
2. Проверьте что `telegram_bot.py` на месте
3. Запустите через командную строку для просмотра ошибок

## 🔄 Пересборка (для разработчиков)

Чтобы пересобрать приложение:
```bash
# Установить браузеры и собрать
install-browsers-and-build.bat

# Или только собрать (если браузеры уже есть)
build.bat
```

Скрипт автоматически:
- Проверит наличие браузеров
- Установит зависимости  
- Соберёт EXE файл
- Создаст папку `Release`
