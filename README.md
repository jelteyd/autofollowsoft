## 🔥 Что делает TwitterWorker?

Мощный инструмент для автоматизации роста и фарминга аккаунтов в **Twitter / X** (2025+).  
Работает через **Playwright** → полностью имитирует реального пользователя.  
Управление и мониторинг — через **Telegram-бота** (можно держать на VPS и не заходить в панель).

<br>

## ✨ Текущие возможности (Genesis)

| Функция                        | Описание                                                                 | Статус    |
|-------------------------------|--------------------------------------------------------------------------|-----------|
| Авто-фолловинг                | Массовый автослединг по списку + заполнение базы                        | ✅        |
| Проверка страны               | Верификация геолокации аккаунта                                         | ✅        |
| Счётчик фолловеров            | Отслеживание роста (временно отключён → скоро вернётся)                 | ✅       |
| Telegram-бот                  | Удалённый запуск, статистика, логи, управление                           | ✅        |
| Поддержка JSON cookies        | Импорт сессий из расширений / экспорта                                  | ✅        |
| HTTP / SOCKS5 прокси          | Полная поддержка ротации прокси                                         | ✅        |
| Рандомные задержки            | 3–5 минут между действиями + рандомные лайки после фоллов             | ✅        |
| Фильтрация твитов             | Игнорирует посты старше 2025 года                                       | ✅        |
| Очистка базы                  | Удаляет записи без страны                                               | ✅        |

## 🚀 Что скоро появится

- Полноценный **Account Farming** (авто-лайки, ретвиты, реплаи)
- Восстановленный и улучшенный **счётчик фолловеров**
- Новый **GUI** (переработанный интерфейс)
- Расширенные команды в Telegram-боте
- **Мультитрединг** — одновременное управление десятками аккаунтов
- Ротация профилей / user-agents / fingerprints
- Антибан-механизмы (более умная имитация поведения)
